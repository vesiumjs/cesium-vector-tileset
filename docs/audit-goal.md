# 全面审计、渲染一致性与性能优化目标

更新：2026-10-14。状态：进行中。本文件明确当前目标的范围、交付物与验收条件。

## 目标

对全部生产源码、公开接口、构建入口和已有测试完成可追踪审计；结合审计时最新稳定版 MapLibre GL JS、Cesium 的固定提交源码，修复已复现的正确性、渲染和资源生命周期缺陷，清理冗余实现、无效测试和重复渲染工作。在相同数据、样式和实际相机下完成俯视、三维倾斜、极限高低 zoom 的画面对比，以重复 A/B 测量验证完整帧耗时、加载速度和资源驻留的改善。

## 必须覆盖的场景

- 平面俯视与三维倾斜；建筑、道路和符号共同存在，验证样式顺序和深度遮挡。
- 实际球面投影与高 zoom 自动 Mercator 分支分别验证；globe 设置名不能证明实际走球面 shader。
- zoom 0、常用城市 zoom、zoom 24/25，覆盖近地、高空、高俯角和近地平线。来源级别与样式 zoom 不同、整数边界、日期线和多视锥作为独立风险验证。
- 密集建筑/符号、大几何、连续平移/旋转/缩放、LOD 交接、样式与来源替换、缓存淘汰和移除释放。

先校准实际相机位置、方向、FOV、视口和地面投影。WGS84 椭球与参考球面的差异需要独立模型证据，不能任意扩大像素容差。选择能触发独立分支的代表组合，不铺满无意义的参数矩阵。

## 完成条件

1. 审计范围有文件级记录；未检查区域和未验证猜测没有写成已完成。
2. 已确认且属于项目支持范围的缺陷修复并回归；关键画面没有未解释或未处理的差异。接受但静默忽略的样式属性属于缺陷。
3. 性能改动经过重复、同条件、完整场景测量；噪声不足以判断时补测。显著退化不能被局部提速掩盖；剩余热点及与 MapLibre 的差距逐项说明。
4. ESLint → 类型检查通过；必要的相关单测、真实 Worker、GPU 画面与交接、发布包和构建验证通过。测试审查有保留/移除依据。
5. 交付改动说明、发现清单、视觉与性能证据索引、明确剩余限制。仍有必验项或确认缺陷未完成时，目标保持进行中。

不以某台机器达到 60 FPS、低于 16.67ms、测试全绿或单次局部提速作为整体完成条件。本轮需要消除已定位的可避免成本并完成场景验收，不能宣称所有场景已达到理论最优。

## 执行优先级

按用户 2026-10-14 补充，先处理收益大的工作，收益小的放到最后：

1. 实际漏绘、错误遮挡/碰撞、样式参数失效、三维倾斜和极限 zoom 的明显差异，以及会阻断加载/交接或持续累积资源的缺陷。
2. 在真实完整帧或加载采样中占比高的重复计算、复制、上传和提交成本；先定位占比，再做可独立归因的改动和重复 A/B。
3. 影响多处实现的模块职责/所有权收敛和重复规则清理。
4. 小幅局部提速、命名、纯风格和低收益包装简化，集中放在后面。审查时可登记，不能打断前述高收益工作。

已经开始的关键修复先完成原触发场景和必要回归。没有性能收益证据的局部优化不继续扩大实验，也不列为主要成果；完整范围与验收条件仍保留。

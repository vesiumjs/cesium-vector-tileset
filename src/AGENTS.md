# Demo 与使用文档

场景只定义相机位置和姿态，样式只定义地图外观，两者独立选择，通过 URL 组合。Demo 使用直观的 Vue 状态和最小 CSS，注释说明用户可参考的接入方法；保留取消与释放等真实生命周期处理。

修改场景、布局或移动端展示后实际截图检查。README 截图只展示地图画面，隐藏控制面板，保留必要版权署名；面板截图留作内部检查。保留 Cesium 自带 FPS；性能面板优先展示当前场景的瓦片、驻留批次、资源量级和耗时，不把提交命令数当作画面元素数量。指标采样保持低开销，说明数量和耗时的含义。README 面向使用者，重点是安装、接入、常用操作、场景链接和截图；审计、内部算法及性能诊断放在对应开发文档中。README 由发布会复制进包内并渲染到 npm，因此链接一律写完整 GitHub 地址（文件用 `blob/main`，目录用 `tree/main`，图片用 `raw.githubusercontent.com`，`blob` 地址不返回图片字节），不使用相对路径。
